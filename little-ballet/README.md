# 004 · 花间小剧场

[在线体验](https://sasafreya.github.io/little-creations/little-ballet/) · [返回合集](../)

无依赖的网页舞蹈原型。`index.html` 为入口；`art.js` 绘制花毯和花束，`dance.js` 管理角色与演出，`lessons.js` 管理芭蕾课堂、节拍和语音。

在 `little-ballet` 目录中预览：`python3 -m http.server 8767 `。

## 芭蕾小课堂

打开页面后选择组合，点击「开始讲解示范」。中文语音由浏览器提供，可关闭；文字动作说明与八拍指示一直随示范更新。支持 0.5、0.75、1 倍速，按八拍跳转、段落选择与进度拖动。播放到组合末尾后收势停止，可重播。

| 组合 | 拍数 | 来源与适配 |
| --- | --- | --- |
| 扶把擦地 | 64 | 皇家芭蕾舞学校公开指南第 2 页：左腿，前、旁、后、旁，每个方向四次；四拍一次，擦出、保持、收回、保持。手位与扶把作插画适配。 |
| 中间手臂 | 16 | 同指南第 3 页前 16 拍节选；低位、一位、五位、二位、低位两遍；原 croisé 朝向简化成正面。 |
| 半蹲与半脚尖 | 32 | 依据 PBT 的动作说明自行编排拍数；脚跟落地半蹲，前脚掌支撑提踵。 |
| 一位二位小跳 | 32 | 皇家芭蕾舞学校指南第 4 页；每八拍六次双脚跳，第七八拍擦地换位，右腿与左腿分别引导。减速示意。 |

## 动作与语音

课堂独立计算支撑脚、工作脚、足跟和脚尖。小跳的支撑脚在换位时保持地面位置，躯干随重心移动。手臂课每两拍一个短语音提示；其他组合按段落讲解，暂停、跳转、换课、离开页面会取消旧语音。浏览器无语音能力或播报失败时提供字幕提示。

课堂为二维插画演示：腿长会随投影简化，擦地前后方向用纵深偏移表达，不能用于精确校正真人动作。课堂是基础组合与节选，尚未实现完整舞剧复刻。

原有独舞、四小天鹅、东方舞仍是风格化原创/简化演出。保留角色手册、花束互动、角落模式、舞台大小与位置记忆。透明桌面窗、置顶、鼠标穿透与原生 Mac 包装尚待实施；角落模式只改变网页布局。

## 验证

运行 `node tests/lessons.test.cjs`：覆盖四组完整时间线的数值与连续性、擦地保持拍、落地脚尖、24 次小跳、左右引导腿的固定支撑脚、手位端点，以及开始、暂停、跳转、语音取消、速度、结束、重播。

JavaScript 语法：`node --check dance.js` 和 `node --check lessons.js`。

浏览器验证：课堂载入、开始与暂停、组合切换、分段定位、半速选择、滑杆定位至五位手、完整手臂组合的自动结束；该轮检查未出现控制台错误。语音开始/结束回调已触发，未单独试听音色。

## 手脚连续性修正

- 手臂采用连续肘部方向与弧形轮廓，取消肩线处的硬切换；手腕与手指另绘柔和延伸。
- 直腿与屈膝共用连续膝部几何，取消屈膝阈值处切换画法；舞鞋改为带脚跟、脚背和圆脚尖的轮廓。
- 上述绘制同时用于独舞、四小天鹅、东方舞和课堂。
- 回归检查覆盖实际绘制肘点的逐帧连续性，以及旧屈膝阈值附近的膝点连续性。
